

# AI陪练小程序 — 产品设计与实现方案

## 设计风格
简白底色 + 淡蓝色主色调，圆角卡片布局，清爽简约，移动端优先（max-width 430px 居中展示）

## 信息架构（4个底部Tab）

### Tab 1：首页
- **顶部搜索栏** + 消息通知图标
- **Banner轮播** — 核心课程/活动推广（2-3张）
- **碎片化学习入口** — 首屏视觉重心位置，大按钮卡片，点击进入短视频内容流页面
- **快捷功能网格** — 课程库、AI对练、考试中心、知识库、排行榜等图标入口
- **推荐课程列表** — 横向滚动卡片，显示封面、标题、学习人数、评分

### Tab 2：学习
- **学习路径列表** — 按计划/章节组织，显示进度条
- **章节详情页** — 视频课程列表 + 课后练习入口 + 考核入口
- **AI陪练入口（核心练兵场）** — 三种模式切换：
  - 文本对话模式：聊天界面，AI扮演角色，用户文字回复
  - 语音+文本模式：语音输入按钮，对话文本展示，AI实时反馈
  - 视频模拟模式：播放真人视频片段，用户观看后回答，AI评分
- **考核页面** — 两种形式：
  - 问卷客观题考试（选择题/判断题）
  - AI视频实战考试（一问一答式，播放视频提问+用户作答+AI评分）

### Tab 3：社区
- **打卡日历** — 周视图，标记每日打卡状态，打卡按钮
- **勋章墙** — 练习次数勋章、高水平表现勋章、坚持打卡勋章等，已获得/未获得状态
- **排行榜** — 切换Tab（总榜/同岗位榜/周榜），显示头像、昵称、分数、勋章数
- **AI问答助手** — 页面右下角悬浮按钮，点击展开聊天窗口，支持业务知识问答

### Tab 4：我的
- **个人信息卡片** — 头像、昵称、岗位、学习天数统计
- **课程历史** — 已学/在学课程列表
- **练习复盘** — AI陪练记录列表，点击进入单次复盘报告：
  - 综合评分 + 雷达图能力分析
  - 对话文本还原 + 逐句AI点评（高亮优秀/待改进）
  - 改进建议清单
- **成长地图** — 岗位晋升路径可视化（当前位置→各阶段→目标岗位），每个阶段关联知识点和课程
- **岗位胜任力评估** — 能力模型数据概览 + 各维度匹配度进度条 + 课程推荐

## 关键页面交互流程

### AI陪练页面 User Flow
1. 选择练习场景（如"客户投诉处理"）→ 选择模式（文本/语音/视频）
2. 进入对练 → AI先设定场景描述 → 用户回复 → AI根据角色反馈
3. 对练过程中显示实时评分提示（如"表达清晰 ✓"）
4. 结束对练 → 显示总分 + 简要评价 → 可查看详细复盘报告

### 单次练习复盘报告 User Flow
1. 顶部：综合得分（大数字）+ 能力雷达图
2. 中部：完整对话还原，每句话旁标注AI点评气泡
3. 底部：改进建议列表 + 推荐相关课程 + 再练一次按钮

## 实现范围
- 全部使用mock数据构建完整UI原型
- 移动端优先布局，PC端居中展示
- 所有4个Tab页面 + 碎片化学习页 + 章节详情页 + AI对练页 + 考核页 + 复盘报告页 + 成长地图页 + 胜任力评估页
- AI问答悬浮按钮全局可见
